### 3.2 核心控件选型

**中央部件必须用 `QTextEdit`，不能用 `QPlainTextEdit`。**

理由：第 3 项要求"字体、颜色、粗体、斜体、下划线"，第 9 项要求"项目编号、项目符号"——这些都是富文本能力。`QPlainTextEdit` 只处理纯文本，无法承载字符格式与列表，选它后面必然推倒重来。

`QTextEdit` 同时免费提供：
- 撤销 / 重做栈 → 直接支撑"撤销、重复键入"；
- `QTextDocument::find()` → 支撑查找；
- `QTextCursor::charFormat()/blockFormat()` → 支撑格式刷；
- `QTextEdit::print(QPrinter*)` → 支撑打印；
- `zoomIn()/zoomOut()` → 支撑状态栏缩放。

### 3.3 文件保存策略

富文本编辑器有个绕不开的取舍：存 `.txt` 会丢掉全部格式。建议**按扩展名分流**：

- 过滤 `.txt` → `toPlainText()`（记事本语义，保真度低但通用）
- 过滤 `.html` / `.htm` → `toHtml()`（完整保留格式）
- 打开时同样按扩展名判断用 `setPlainText()` 还是 `setHtml()`

这样"打开自己刚存的 html 能还原格式"就成了一个很直观的演示点。

## 四、逐项实现方案

### 1. 文件菜单（14 分）

新建、打开、保存、另存为、页面设置、打印、退出，各 2 分。

| 功能 | 实现要点 |
|---|---|
| 新建 | `clear()`；关闭前用 `maybeSave()` 检查 `document()->isModified()`，弹 `QMessageBox` 三选（保存/不保存/取消） |
| 打开 | `QFileDialog::getOpenFileName`，按后缀 `setPlainText` / `setHtml` |
| 保存 | 若 `m_currentFile` 为空则转"另存为"，否则直接写盘并 `setModified(false)` |
| 另存为 | `QFileDialog::getSaveFileName` + 更新 `m_currentFile` + 刷新窗口标题 |
| 页面设置 | `QPageSetupDialog`（注意：Qt 6 中需 `#include <QtPrintSupport/QPageSetupDialog>`，且 CMake 要 `find_package(... PrintSupport)` 并链接 `Qt6::PrintSupport`） |
| 打印 | `QPrintDialog` + `QTextEdit::print(printer)` |
| 退出 | `close()`，复用 `maybeSave()` |

**窗口标题**建议做成 `文件名[*] - 255025127Test`，`[*]` 让 Qt 自动加 `*` 表示未保存，一行代码换一个很专业的观感：

```cpp
setWindowTitle(QString("%1[*] - 255025127Test").arg(displayName));
```

**注意**：现有 `CMakeLists.txt` 只链接了 `Qt::Widgets`，打印相关功能需要补 `PrintSupport`。

### 2. 编辑菜单（26 分）

复制、剪切、粘贴、删除各 2 分；撤销、重复键入各 2 分；替换 2 分；**查找 8 分**；全选、时间/日期。

**初始置灰**（要求明确写了"复制，剪切、删除，查找一开始为灰色"）：

| 动作 | 启用条件 |
|---|---|
| 复制 / 剪切 / 删除 | `textEdit->textCursor().hasSelection()` |
| 查找 | 文档非空，即 `!textEdit->toPlainText().isEmpty()` |
| 粘贴 | 由系统剪贴板是否有内容决定（可选，做出来更严谨） |

实现方式是连 `QTextEdit::copyAvailable(bool)` 与 `selectionChanged()` 信号到统一的 `updateEditActions()` 槽，**不要**在各个操作里零散地 `setEnabled`，否则很容易出现"选中文本后按钮还是灰的"这类状态不同步。

**查找对话框（8 分，重头戏）**

按截图做非模态对话框（`show()` 而不是 `exec()`，这样才能反复点"查找下一个"）：

- 控件：`QLineEdit` + `QPushButton`(查找下一个/取消) + `QGroupBox`(方向: 向上/向下 `QRadioButton`) + `QCheckBox`(区分大小写 / 循环)
- 核心：

```cpp
QTextDocument::FindFlags flags;
if (m_caseSensitive->isChecked()) flags |= QTextDocument::FindCaseSensitively;
if (m_up->isChecked())          flags |= QTextDocument::FindBackward;

bool found = m_editor->find(text, flags);
if (!found && m_wrap->isChecked()) {          // 循环：回到另一端再找一次
    QTextCursor c = m_editor->textCursor();
    c.movePosition(m_up->isChecked() ? QTextCursor::End : QTextCursor::Start);
    m_editor->setTextCursor(c);
    found = m_editor->find(text, flags);
}
if (!found) QMessageBox::information(this, "查找", "找不到\"" + text + "\"");
```

- **替换**：在两个 `QLineEdit`（查找内容 / 替换为）基础上加"替换 / 全部替换"。全部替换用 `QTextCursor` 循环 `find` + `insertText`，**注意每次替换后光标要前进**，否则会死循环。查找与替换建议放同一个对话框的两个页签，或一个对话框上下两块。

### 3. 格式菜单（12 分）

字体、颜色各 2 分；粗体、斜体、下划线各 2 分；更改大小写 2 分。

- **字体**：`QFontDialog::getFont()`
- **颜色**：`QColorDialog::getColor()` → 设置 `setForeground`（字体颜色）与 `setBackground`（高亮底色）两个入口
- **粗体/斜体/下划线**：三个 checkable `QAction`，用 `setFontWeight / setFontItalic / setFontUnderline`，并在 `currentCharFormatChanged` 信号里回读状态同步按钮的按下态
- **更改大小写**：大写 / 小写用 `selection().toUpper()/toLower()`；"句首字母大写""切换大小写"需手写遍历逻辑

以上三项都要在工具栏有图标——工具栏放 `QFontComboBox`（字体）与 `QComboBox`（字号，或用可编辑的 `QComboBox` 让用户手输）。

### 4. 对齐方式（8 分，无菜单）

四个 checkable `QAction` 组成互斥组（`QActionGroup`）：

```cpp
auto *group = new QActionGroup(this);
group->setExclusive(true);
// 左对齐
auto *alignLeft = new QAction(QIcon(":/icons/align_left.png"), "左对齐", this);
alignLeft->setCheckable(true);
group->addAction(alignLeft);
connect(alignLeft, &QAction::triggered, this, [this]{
    m_editor->setAlignment(Qt::AlignLeft | Qt::AlignAbsolute);
});
// 右/居中/两端同理：AlignRight / AlignHCenter / AlignJustify
```

两端对齐对应 `Qt::AlignJustify`。注意切回左对齐时要带上 `Qt::AlignAbsolute`，否则在 RTL 文本下会按起始边解释。

### 5. 字体、字号（8 分，无菜单）

- **字体**：工具栏 `QFontComboBox`，`connect(currentFontChanged)` → `setFontFamily`；同时用 `currentCharFormatChanged` 反向同步下拉框
- **字号**：`QComboBox`（可编辑，预置 8~72 常用值），失焦或回车时 `setFontPointSize`
- **字体变大变小**：两个 `QAction`（`Ctrl+Shift+.` / `Ctrl+Shift+,` 或加号减号），实现为"当前字号 ±1（或 ×1.1）"

字号变化建议对**选区**生效，无选区时对后续输入生效——`mergeCurrentCharFormat()` 天然满足这个语义。

### 6. 状态栏页面缩放（5 分，无菜单）

状态栏右侧放 `QLabel("100%") + QToolButton(−) + QSlider + QToolButton(+)`，滑块范围 25~400：

```cpp
connect(slider, &QSlider::valueChanged, this, [this](int v){
    m_editor->zoomIn(v - m_zoom);   // zoomIn 接受相对步数
    m_zoom = v;
    m_zoomLabel->setText(QString("%1%").arg(v));
});
```

滑动时禁用信号回环（`blockSignals` 或标志位），否则"滑块 → zoom → 同步滑块"会抖动。

### 7. 格式刷（8 分，无菜单）

工具栏一个 checkable `QAction`。状态机放在 `core/formatpainter`：

1. 点击格式刷 → 记录当前光标的 `QTextCharFormat` 与 `QTextBlockFormat`，进入"待刷"状态
2. 在编辑区按下并拖选 → 松开鼠标时把记录的格式 `mergeCharFormat` / `setBlockFormat` 到选区
3. 单击刷一次后自动复位；双击图标进入"连续刷"模式（可选加分项）

实现路径二选一：给 `QTextEdit` 装 `eventFilter` 拦 `MouseButtonRelease`（更可控），或连 `selectionChanged`（更省事但有边界情况）。

### 8. 字数统计（4 分，无菜单）

状态栏一个可点击 `QLabel`，点击弹对话框，对话框内容按截图排布。

核心算法放 `core/textstatistics.cpp`，纯函数、不依赖 UI：

```cpp
struct StatResult {
    int pages, words, charsNoSpace, charsWithSpace;
    int paragraphs, lines, nonCjkWords, cjkChars;
};

StatResult compute(const QTextDocument *doc) {
    StatResult r{};
    r.pages          = doc->pageCount();
    r.paragraphs     = doc->blockCount();
    const QString text = doc->toPlainText();
    r.charsWithSpace = text.length();
    r.charsNoSpace   = QString(text).remove(QRegularExpression("\\s")).length();

    // 行数：按每个 block 的实际排版行数累加（能正确处理自动换行）
    for (QTextBlock b = doc->begin(); b.isValid(); b = b.next())
        r.lines += b.layout()->lineCount();

    // 中文/朝鲜语字符数
    for (QChar ch : text)
        if (isCjk(ch)) ++r.cjkChars;

    // 非中文单词数：连续拉丁字母/数字串的个数
    static const QRegularExpression wordRe("[A-Za-z0-9_']+");
    auto it = wordRe.globalMatch(text);
    while (it.hasNext()) { it.next(); ++r.nonCjkWords; }

    // "字数" = 中文字符数 + 非中文单词数 —— 与 Word 的口径一致
    r.words = r.cjkChars + r.nonCjkWords;
    return r;
}
```

两个容易踩的坑：
- **"字数"不是 `characterCount()`**。Word 的"字数"对中文按下述口径：一个汉字算 1 个"字"，一串英文单词算 1 个"字"。直接用 `document()->characterCount()` 会把 "hello" 算成 5，和老师拿 Word 对照时对不上。
- **行数不能只数 `\n`**。文档开了自动换行后，一个逻辑段落会占多个显示行，必须用 `block.layout()->lineCount()` 累加。

`isCjk()` 判断范围：`0x4E00–0x9FFF`（基本区）、`0x3400–0x4DBF`（扩展 A）、`0xAC00–0xD7AF`（谚文）。

### 9. 项目编号 / 项目符号（15 分，无菜单）

工具栏两个 `QToolButton`（带下拉菜单）：

- **项目符号**：`QTextListFormat::ListDisc` / `ListCircle` / `ListSquare`
- **项目编号**：`ListDecimal`（`1. 2. 3.`）、`ListLowerAlpha`（`a) b) c)`）、`ListUpperAlpha`、`ListLowerRoman`、`ListUpperRoman`

```cpp
QTextCursor c = m_editor->textCursor();
QTextListFormat fmt;
fmt.setStyle(QTextListFormat::ListDecimal);
c.createList(fmt);
```

**难点在截图里的 `一、二、三、` 和 `(一)(二)(三)`** —— Qt 没有内置这两种中文编号样式。用 `QTextListFormat` 的前后缀接口构造：

```cpp
fmt.setStyle(QTextListFormat::ListDecimal);
fmt.setNumberPrefix("第");
fmt.setNumberSuffix("、");
```

注意 `setNumberPrefix/setNumberSuffix` 是 Qt 5.15+ 的接口（Qt 6 可用），但**它只支持阿拉伯数字的前后缀**，做不出"一、二、三"的中文数字。要完全还原截图效果，需要：
- 方案 A：用 `ListUpperRoman` 之类最接近的内置样式交付（可接受的近似）；
- 方案 B：重写 `QTextDocument` 的列表编号绘制（工作量大，不建议）；
- 方案 C：用 `ListDecimal` + 前缀"第"后缀"、" 做 `第1、第2、`，视觉上接近且明显是"编号"。

**建议 A + C 组合**：`无 / 1. / 1) / a) / A. / i. / I. / • / ○ / ▪` 用内置样式完整还原，中文序号用方案 C 近似。评分点上"能列出编号库并正确应用"通常就给分，不必强求字形完全一致。

取消列表用 `c.setBlockFormat(blockFmt)`（去掉 `objectIndex`）或再点一次按钮切换。

## 五、拓展考点实现

### 自动换行切换
`QTextEdit::setLineWrapMode(WidgetWidth / NoWrap)` + 一个 checkable `QAction`。关掉自动换行后必须开水平滚动条，否则长行看不见：

```cpp
connect(wrapAction, &QAction::toggled, this, [this](bool on){
    m_editor->setLineWrapMode(on ? QTextEdit::WidgetWidth : QTextEdit::NoWrap);
    m_editor->setHorizontalScrollBarPolicy(on ? Qt::ScrollBarAlwaysOff
                                              : Qt::ScrollBarAsNeeded);
});
```

### 插入特殊符号
工具栏 `QToolButton` + `QMenu`，菜单项用 `QWidgetAction` 塞一个 `QGridLayout` 的符号按钮网格（截图里的 ○ φ Φ □ ● …），底部一项"其他符号(M)..."打开 `symboldialog`（`QFontComboBox` 选字体 + `QTableWidget` 字符网格，双击插入）。

### 分栏（**全项目最高风险项**）
Qt 的 `QTextDocument` **没有**多栏流式排版能力，`QTextFrameFormat` 里也没有列数属性。可行方案：

- **方案 A（推荐，稳）**：伪分栏 —— 把内容包进一个 1×N 的 `QTextTable`，单元格间距设为列间距，边框隐藏。文字在各单元格内自动换行，观感与分栏一致，且实现只需几十行：

```cpp
QTextTableFormat tf;
tf.setColumnCount(n);
tf.setBorder(0);
tf.setCellPadding(8);
QTextCursor c = m_editor->textCursor();
c.insertTable(1, n, tf);   // 再把原内容分配进各单元格
```

- **方案 B（进阶，慎选）**：继承 `QAbstractTextDocumentLayout` 自行实现列式重排与绘制。能做到真正的"文字从第一栏流到第二栏"，但需要处理 `documentSize()`、`draw()` 与光标命中，工作量大、调试困难。

**建议：方案 A 交付，在实验报告里说明取舍**（老师多半也清楚 Qt 的限制，能讲清楚为什么不选 B 反而是加分项）。菜单项按截图给 `一栏 / 两栏 / 三栏`，`偏左 / 偏右` 再加 `更多分栏` 对话框。

### 自动保存定时设置
拆成三部分，放 `core/autosavemanager`：

1. **定时缓存**：`QTimer`，间隔从 `QSettings` 读（1/3/5/10 分钟，默认 5）。只在 `document()->isModified()` 为真时写盘，避免无谓 IO。
2. **备份落盘**：写到 `QStandardPaths::writableLocation(AppDataLocation) + "/backup/"`，文件名带原始文件名 + 时间戳。同时用 `QSettings` 记录"备份文件 ↔ 原文件"的映射与原文件 mtime。
3. **异常恢复**：启动时扫备份目录，若某备份比原文件新（或原文件已不存在），弹 `QMessageBox` 询问"检测到未正常关闭，是否恢复备份？"。
4. **状态栏闪烁提示**：保存完成后连切 3 次图标（`QTimer` 100ms×6 次切回），状态栏 24×24 图标。
5. **设置弹窗**：`autosavedialog` 里一个 `QComboBox`（1/3/5/10 分钟）+ 立即保存/确定/取消，写回 `QSettings`。

**关键细节**：恢复动作必须区分"用户主动保存过"和"只是自动备份过"。否则会出现"用户存了盘、正常关闭、下次启动却被问要不要恢复旧备份"——这会让演示翻车。判断依据用**备份时间戳 > 原文件 mtime**。

### 插入表格
工具栏 `QToolButton` + 弹出网格选择器（`QWidgetAction` 内自绘 N×M 方格，鼠标悬停高亮到前 i 行 j 列），点击即 `QTextCursor::insertTable(rows, cols)`。另给一个对话框入口 `插入表格(I)...` 供手输行列。截图里的"绘制表格""Excel 电子表格""快速表格"属 Word 独有功能，**不在需求文字范围内，可只做菜单项的禁用占位或不实现**。

## 六、图标资源方案

1. 到 iconfont.cn 下载，工具栏统一导出 **32×32 PNG**，状态栏 **24×24**，缩放控件 **16×16 或 24×24**。
2. 全部放进 `resources/icons/`，在 `resources/resources.qrc` 里登记：

```xml
<RCC>
  <qresource prefix="/icons">
    <file>icons/new.png</file>
    <file>icons/open.png</file>
    <!-- ... -->
  </qresource>
</RCC>
```

3. `CMakeLists.txt` 里把 `resources/resources.qrc` 加进 `PROJECT_SOURCES`；`CMAKE_AUTORCC` 已开，会自动编译，无需额外配置。
4. 代码中一律用 `QIcon(":/icons/new.png")` 引用。

**建议**：图标是纯美术工作，**尽早下载备齐**。做到一半发现缺图标再去凑，很容易因为风格不一导致界面显得杂乱。至少覆盖：新建/打开/保存/另存为/页面设置/打印/退出、复制/剪切/粘贴/删除/撤销/重做/查找/替换/全选/时间、字体/颜色/粗体/斜体/下划线/大小写、四个对齐、字号增减、格式刷、编号、符号、表格、分栏、换行、设置、缩放加减。

## 八、风险与对策

| 风险 | 等级 | 影响 | 对策 |
|---|---|---|---|
| **分栏** | 高 | Qt 无原生多栏排版，硬做真分栏可能耗掉一整天 | 用 `QTextTable` 伪分栏交付；报告中说明取舍 |
| **中文编号 `一、二、三`** | 中 | Qt 内置列表样式不含中文数字 | 用 `ListDecimal` + 中文前后缀近似；其余样式完整还原 |
| **字数统计口径与 Word 对不上** | 中 | 老师现场拿 Word 对照验证 | 用"汉字数 + 拉丁单词数"口径，不直接用 `characterCount()` |
| **自动备份误报恢复** | 中 | 演示时弹出不该弹的恢复框 | 用备份时间戳 > 原文件 mtime 判断；正常退出时清理备份 |
| **格式刷交互边界** | 中 | 无选区点击、连续点击行为混乱 | `eventFilter` 拦鼠标释放，明确单次/连续两种模式 |
| **`MainWindow` 膨胀** | 中 | 后期改一处错要翻几百行 | 按第三节目录结构提前拆出 `dialogs/` 与 `core/` |
| **`QAction` 状态不同步** | 中 | 按钮按下态与实际格式不符 | 统一由 `currentCharFormatChanged` / `cursorPositionChanged` 驱动刷新 |
| **打印模块链接失败** | 低 | 编译报错找不到 `QPrintDialog` | CMake 补 `find_package(... PrintSupport)` 与 `target_link_libraries(... Qt6::PrintSupport)` |
