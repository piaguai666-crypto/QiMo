# 255025127 jsy

基于 Qt 6 Widgets 开发的仿记事本文本编辑器，完成《嵌入式驱动编程》期末测试要求。

## 功能

- **文件**：新建、打开、保存、另存为、页面设置、打印、退出
- **编辑**：复制、剪切、粘贴、删除、撤销/重复键入、查找、替换、全选、插入时间/日期
- **格式**：字体、颜色、粗体、斜体、下划线、更改大小写
- **排版**：左/右/居中/两端对齐、字号变大变小、格式刷、项目符号/编号
- **辅助**：字数统计、插入表格、插入特殊符号、自动换行切换、分栏
- **自动保存**：可设置 1/3/5/10 分钟定时自动保存，后台缓存文档，异常重启可恢复备份，完成时状态栏图标闪烁提示

## 编译方式

依赖：Qt 6（Widgets）、CMake ≥ 3.16、C++17 编译器。

```bash
cmake -S . -B build
cmake --build build
```

构建产物位于 `build/` 目录，运行 `./build/<项目名>` 即可启动。
